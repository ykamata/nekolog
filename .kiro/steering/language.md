# 言語・コミュニケーション規則

## 基本言語設定

- **主要言語**: 日本語
- **コード内コメント**: 日本語
- **変数名・関数名**: 英語（技術的慣例に従う）
- **ドキュメント**: 日本語

## AI アシスタント応答規則

### 出力言語

- チャットでの会話は日本語で行う
- 技術的な説明や手順も日本語で提供する
- エラーメッセージの説明は日本語で行う
- コードの説明やコメントは日本語で記述する

### コミュニケーションスタイル

- 丁寧語を使用し、親しみやすい口調を心がける
- 技術用語は適切な日本語訳を使用し、必要に応じて英語を併記する
- 複雑な概念は段階的に説明する

## コード内言語規則

### コメント

```typescript
// 猫の食事記録を取得する関数
async function getMealRecords(catId: string) {
  // データベースから記録を検索
  return await prisma.mealRecord.findMany({
    where: { catId }
  })
}
```

### エラーメッセージ

- ユーザー向けエラーメッセージは日本語
- 開発者向けログは英語でも可

### データベース

- テーブル名・カラム名: 英語（snake_case）
- データ内容: 日本語対応（UTF-8）

## ドキュメント規則

- README、仕様書、コメントは日本語で記述
- API ドキュメントは日本語で説明を付ける
- テストケースの説明は日本語で記述
